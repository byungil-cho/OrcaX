동작 흐름(요약)
  1. 관리자가 기본가·배수 저장 → 현재 가격 즉시 반영.
  2. 유저가 “씨옥수수 구매” 클릭 → 모달에서 수량 선택.
  3. 검증: 보유 ORCX, 보유 한도(2개), 재고 확인.
  4. 확정 시: ORCX 차감, 인벤토리 증가, 관리자 재고 감소.
  5. 팝콘: 옥수수≥1 & 첨가물≥1 → 버튼 활성화 → 제작 시 각 1개 소모.
