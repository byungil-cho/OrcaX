옥수수 농장 - 물/거름 부족 시 상태 변화 로직

아래는 옥수수 농장의 성장 상태가 물과 거름의 부족 상황에 따라 어떻게 변화하는지에 대한 설계입니다.

1. 기본 개념

  • 옥수수 성장 상태는 100% → 70% → 50% → 30% 단계로 하락.
  • 물과 거름이 모두 정상(>0)이면 감소 없음.
  • 부족 시 일정 주기(예: 10분)에 따라 단계적으로 상태 이미지 변경.

2. 상태 하락 속도

  • 물=0, 거름>0 → 저하 속도 = 1배 (기본 저하)
  • 물>0, 거름=0 → 저하 속도 = 1배 (기본 저하)
  • 물=0, 거름=0 → 저하 속도 = 2배 (가속 저하)

3. 이미지 변화 규칙

  • 100% 상태 → 물·거름 부족 시 70% 이미지로 변경
  • 70% 상태 → 계속 부족 시 50% 이미지로 변경
  • 50% 상태 → 계속 부족 시 30% 이미지로 변경
  • 물/거름 다시 채우면 해당 %구간에 맞는 상승 이미지 표시

4. 회복 로직

  • 물과 거름 모두 1 이상 채워짐 → 성장 속도 정상화
  • 상태 %구간에 맞춰 해당 구간의 이미지를 즉시 표시
  • 다음 성장 주기마다 상위 단계로 회복 (예: 50% → 70% → 100%)
참고: 이 로직은 기존 감자/보리 농장 로직과 독립적으로 운영되며, 로그인 시 유저 데이터는 공통으로 불러오되 옥수수 전용 성장 상태와 이미지는 별도로 관리됩니다.
